# RAG Restaurant Review QA

A simple RAG system that answers questions using restaurant reviews, LangChain, ChromaDB, and Ollama.

## Setup

```bash
pip install -r requirements.txt
ollama pull mxbai-embed-large
ollama pull llama3.2
```

## Run

```bash
py main.py
```

## Stack

Python · LangChain · Ollama · ChromaDB · Pandas
